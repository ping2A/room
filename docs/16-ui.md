# 16 — UI: 2D drawing, fonts, menus, status bars, HUD, automap, intermission (`ferrite-ui`)

GZDoom references: `src/common/2d/v_draw.cpp` (DrawTexture + `DTA_*` tags), `src/common/fonts/*`,
`src/common/menu/*` + `wadsrc/static/zscript/engine/ui/menu/*`, `src/g_statusbar/*`
(`sbarinfo.cpp`, `shared_sbar.cpp`), `wadsrc/static/zscript/ui/statusbar/*` (Doom/Heretic/Hexen/Strife bars, alt HUD),
`src/am_map.cpp`, `src/intermission/*`, `src/wi_stuff.cpp`, `src/f_wipe.cpp`, `src/st_stuff.cpp`, `src/ct_chat.cpp`.

## 1. Model

- `ferrite-ui` has **no GPU dependency**. It produces a `UiDrawList` each frame from `SimView` + UI state; the renderer draws it (`13 §11`).
- UI logic ticks at 35 Hz on `UiClock` (independent of the sim, keeps running while paused); drawing happens every frame with a `ticfrac` for smooth animation.
- UI scope WASM modules plug in through registered status bars, menus, and `RenderOverlay/Underlay` events.

### 1.1 DrawTexture semantics

Port `DrawTexture` and the `DTA_*` tag set as a builder: `DTA_320x200`, `DTA_VirtualWidth/Height(F)`, `DTA_Fullscreen(Scale)`, `DTA_DestWidth/Height(F)`, `DTA_CleanNoMove(_1)`, `DTA_Clean`, `DTA_KeepRatio`, `DTA_TopOffset/LeftOffset(F)`, `DTA_WindowLeft/Right(F)`, `DTA_ClipTop/Bottom/Left/Right`, `DTA_Masked`, `DTA_HUDRules`, `DTA_CenterOffset`, `DTA_CenterBottomOffset`, `DTA_FlipX/Y`, `DTA_SrcX/Y/Width/Height`, `DTA_Alpha`, `DTA_FillColor`, `DTA_TranslationIndex`, `DTA_ColorOverlay`, `DTA_Color`, `DTA_Desaturate`, `DTA_RenderStyle`, `DTA_LegacyRenderStyle`, `DTA_ScaleX/Y`, `DTA_Rotate`, `DTA_ViewportX/Y/Width/Height`, `DTA_Internal*`. The virtual-resolution and aspect-ratio rules (`ui_screenborder_classic_scaling`, `uiscale`, `hud_aspectscale`, 4:3 vs widescreen handling with `vid_scale_customwidth/height`) must match GZDoom so mod HUD layouts line up. Widescreen asset support: `game_widescreen_gfx.pk3` and wide `STBAR`/title graphics.

## 2. Fonts

- Font registry (`FontDefs`): built-in `SmallFont` (`STCFN*`), `SmallFont2`, `BigFont` (`FONTB*` / Doom `DBIGFONT` lump), `ConFont`, `IntermissionFont` (`WINUM*`), `NewConsoleFont`, `NewSmallFont` (Unifont-based, for Unicode text in menus/messages; `ui_generic` CVar), `OriginalSmallFont`, `OriginalBigFont`, HUD fonts for each game's status bar numbers.
- Sources: FON1/FON2/BMF lumps, per-glyph directories (`fonts/<name>/`), FONTDEFS templates, sprite-based fonts, Unifont HEX, TrueType (Ferrite extension).
- Text colours: `TEXTCOLO` ranges (Brick, Tan, Gray, Green, Brown, Gold, Red, Blue, Orange, White, Yellow, Untranslated, Black, LightBlue, Cream, Olive, DarkGreen, DarkRed, DarkBrown, Purple, DarkGray, Cyan, Ice, Fire, Sapphire, Teal + custom), applied by building per-font colour translation tables (`FFont::BuildTranslations`).
- Text layout: `V_BreakLines` (word wrap by pixel width, keeps colour escapes), kerning per font, `\c` escapes, localization (`$KEY` lookups at display time), right-to-left not required.

## 3. Menus

## 4. Status bars and HUDs

- **Native built-in bars** (Rust, port from ZScript `ui/statusbar/*.zs`): `DoomStatusBar` (`STBAR`, ammo/health/arms/frags/armor/keys/ammo counts, mugshot `STF*` faces with all states: `ouch`, `rampage`, `god`, `dead`, `evil grin`, directional pain), `HereticStatusBar` (chain gem animation, inventory bar, `LIFEGEM` translation per player), `HexenStatusBar` (class-specific bars, mana, weapon pieces, inventory), `StrifeStatusBar` (popups: keys/mission/objectives, inventory bar, log), Doom fullscreen HUD (`hud_*` CVars), **AltHUD** (`ALTHUDCF`), crosshairs (`crosshair`, `crosshaircolor`, `crosshairhealth`, `crosshairscale`, `crosshairgrow`), `screenblocks` sizes with border (`gameinfo.border`), `st_scale`/`hud_scale`.
- **SBARINFO** interpreter (port `sbarinfo.cpp` + `sbarinfo_commands.cpp`): `base`, `height`, `interpolatehealth`, `interpolatearmor`, `completeborder`, `monospacefonts`, `lowerhealthcap`, `resolution`, `statusbar normal|fullscreen|automap|inventory|inventoryfullscreen|popuplog|popupkeys|popupstatus { … }`, `mugshot`, `createpopup`, commands (`drawimage`, `drawnumber`, `drawswitchableimage`, `drawmugshot`, `drawselectedinventory`, `drawinventorybar`, `drawbar`, `drawgem`, `drawshader`, `drawstring`, `drawkeybar`, `gamemode`, `playerclass`, `aspectratio`, `isselected`, `usesammo`, `usessecondaryammo`, `hasweaponpiece`, `inventorybarnotvisible`, `weaponammo`, `ininventory`, `alpha`, `else`, `armortype`, `health`/`armor` thresholds…).
- **Module status bars** (`reg_status_bar`): replace via `gameinfo.statusbarclass` or MAPINFO; get `Draw(state, ticfrac)`, `Tick`, etc. (`12 §9`).
- **HUD messages** (ACS/module `hud_message`): layered (`HUDMSG_LAYER_UNDERHUD/OVERHUD/OVERMAP`), types (plain, fade out, type-on with sound, fade in/out), ids replacing previous, `hudsize`, clip rects, wrap widths, colours, logging. They live in sim output (persisted) and are drawn by UI.
- Messages: pickup messages, obituaries (`obituary` strings with `%o`, `%k`, `%g`, `%h`, `%p`… substitutions), centre prints, chat, `msg` levels and colours (`msg0color`…), `show_messages`, `con_centernotify`.
- Screen flashes (palette blends) are computed by the renderer post pass from SimView, not here.
- Scoreboards: DM/team frag table (`+showscores`), coop stats.

## 5. Automap (`am_map.cpp` port)

- Line drawing modes: classic (lines coloured by type: one-sided, two-sided floor/ceiling change, secret, locked (LOCKDEFS mapcolor), teleporters, special triggers (`am_showtriggerlines`), portals, interlevel exits, unexplored/`ML_DONTDRAW`, `ML_MAPPED`, computer map (`am_ovcolor`…)), textured (`am_textured`: flat triangles), overlay mode (`am_overlay` with separate colours, `automap_overlay` MAPINFO), rotate (`am_rotate`), follow mode, zoom, pan, grid, marks (`am_setmark`, `am_clearmarks`, mark numbers font), things display (`am_cheat` levels, `am_showthingsprites` sprites instead of triangles), keys (`am_showkeys`), player arrows (Doom/Heretic shapes), stats overlay (`am_showmonsters/secrets/items/time/totaltime/maplabel`), level name / author.
- Colour presets (`am_colorset` 0 custom, 1 Doom, 2 Strife, 3 Raven) and all `am_*color` CVars.
- Line visibility rules: in GZDoom the renderer sets `ML_MAPPED` during its BSP walk, a render→sim write that Ferrite forbids. Instead the renderer returns `seen_lines` bitset per frame; `ferrite-game` applies them to the local player's automap state stored **outside** the deterministic world (`AutomapState`), and the Computer Area Map powerup sets `level.flags` in-sim). Save games store `AutomapState`.

## 6. Intermission, finale, title loop

- **Intermission scripts** (GZDoom `in_epi1`… lumps / MAPINFO `enterpic`/`exitpic` referencing `$IN_xxx` text lumps): `Background`, `Splat`, `Pointer`, `Spots`, `Animation`, `Pic`, `IfEntering`, `IfLeaving`, `IfVisited`, `IfNotVisited`, `IfTravelling`, `NoAutoStartMap`, `Screensize`, `Tile`. Port `wi_stuff.cpp` (`DInterBackground`) and the stats sequence (kills/items/secrets/time/par counting with sounds, Doom 2 vs Doom 1 layouts, coop and DM tables, `wi_percents`, `wi_showtotaltime`, `wi_autoadvance`, `wi_cleantextscale`), Heretic/Hexen/Strife intermissions (Hexen hub text screens, Heretic yah/`IN_*` screens). Modules can replace via `statscreen_*` gameinfo classes in GZDoom — Ferrite: `reg_status_screen` (S).
- **Finales / MAPINFO `intermission` blocks**: `Image`, `Scroller` (Doom bunny scroll), `Fader`, `Wiper`, `TextScreen` (text crawl with `TextSpeed`, `TextColor`, `TextDelay`, flat/pic background, music), `Cast` (Doom 2 cast call with `CastName`, `CastClass`, `AttackSound`), `Link`, `GotoTitle`, `Wipe`, `Music`, `Time`, `Sound`, `Subtitle`. End-game sequences per game (`EndGame1`, `EndGame2`, `EndGame3`, `EndGame4`, `EndGameW`, `EndGameC`, `EndChess`, `EndDemon`, `EndTitle`, `EndPic`, `EndBunny`, `EndCast`, `EndSequence` names).
- **Title loop** (`D_DoAdvanceDemo`): title page/music, credits pages, demo playback (DEMO1–4 lumps; vanilla demos only in compat mode, otherwise skipped with log), `titlemap` (MAPINFO title map with `gameinfo.titlemap`), `advisorytime`.
- **Screen wipes**: melt (vanilla column algorithm with `M_Random`-based initial offsets using the UI RNG), burn, crossfade (`wipetype`).
- **Startup screens** (Hexen/Heretic/Strife graphical startup, Doom text title bar): native only, S priority; web uses its own loading UI.
- **ENDOOM** on quit (optional).

## 7. Strife conversations

Dialogue UI driven by sim conversation state: speaker name, portrait (`Panel`/`Voice` sounds), text with `$` lookups, choices (with item costs, `NO` responses, `Log` entries, `Special` execution done in sim), random greetings, `Goodbye`. Choice selection → `NetCommand::ConversationReply`.

## 8. Localization

All user-visible strings come from `Language` with `$KEY` lookups; locale from `language` CVar (`auto` = OS locale). GZDoom's `language.csv` content for engine strings can be reused under its licence (GPL) — record in `THIRD_PARTY.md`.
